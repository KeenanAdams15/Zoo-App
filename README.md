# Pine City Zoo Mobile App 🦁🗺️

A responsive, mobile-first web application developed as part of the **FNB App Academy** curriculum. This project serves as a practical, guided portfolio piece designed to demonstrate proficiency in front-end design, UI component layout, semantic HTML, and the Software Development Life Cycle (SDLC).

## 🚀 Project Overview

The **Pine City Zoo App** is a simulated digital tour guide for a fictional zoo. It provides virtual visitors with an interactive tool to explore animal exhibits, navigate the park layout, view live weather, and submit feedback. The project emphasizes clean code structure, reusable CSS components, and intuitive mobile UX principles like sticky navigation.

## ✨ Features

- **🗺️ Interactive Map & Navigation:** A clean home screen designed for seamless park exploration.
- **🦁 Animals Directory:** Multi-media rich profiles detailing various animal exhibits with responsive image grids.
- **📍 Places of Interest:** A dedicated section highlighting park landmarks, amenities, and resting areas.
- **☀️ Live Weather Module:** A simulated widget providing real-time weather updates to help visitors plan their trip.
- **📝 Visitor Feedback Form:** A structured form layout for user queries and reviews, utilizing HTML5 validation rules.
- **📱 Mobile-Optimised UI:** Built with a mobile-first design strategy, featuring sticky header and footer tab navigation bars.

## 🛠️ Tech Stack & Concepts

- **Languages:** HTML5, CSS3
- **Layout Methodologies:** CSS Flexbox & CSS Grid for card layouts and alignment
- **UX/UI Best Practices:** Reusable components, consistent color variables, typography hierarchy, and persistent layouts
- **SDLC Phases Covered:** Requirement Analysis, UI Wireframing, Implementation (Prototyping), and Manual Testing

## 🔧 Getting Started

To run this project locally, follow these simple steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the Project Directory:**
   ```bash
   cd pine-city-zoo-app
   ```
3. **Open the Project:**
   Open `index.html` directly in your preferred web browser, or launch it using an extension like **Live Server** in VS Code.
